主评测的 100 个新开局在训练前固定，最终棋盘互不重复，并与选拔和旧独立评测排除重复。候选由训练阶段的选拔结果选择，未根据主评测调整模型、参数或重复挑选。候选和原模型在主评测中均使用 64 次搜索、7.5 贴目、中国数子规则及连续两次 PASS 终局。GNU Go 和 C++ 检查样本较少，只作为辅助证据；本结果不等于线上 Arena 积分或通用棋力等级。

比赛程序修正了默认六次 PASS、忽略显式两次 PASS 的问题，终局搜索回报统一为胜 +1、负 −1、和 0。关闭提子启发式时直接使用搜索着法。

推理核对最初用显卡默认近似计算作参考，出现约 0.00114 的偏差；关闭该近似计算后，与 CPU 标准精度的差异降至约 0.000006。最终导出核对以实际 C++ 使用的 CPU FP32 为参考，未放宽误差门槛。训练和主评测的对战配置没有因此改变。训练及后端回归测试 47 项通过。
