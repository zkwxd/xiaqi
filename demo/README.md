# 夏棋 · 强化学习 Demo

把 256 局自我对弈训练的成果变成可玩的九路围棋演示。

## 启动

Windows 下解压后双击 `start-demo.cmd`。需要 Python 3.11 或更高版本；首次启动会安装网页服务依赖，之后可离线运行。不需要 Docker、显卡或训练框架。

浏览器自动打开演示页。保持启动窗口运行，按 Ctrl+C 结束服务。优先使用 http://127.0.0.1:8000；端口被占用时自动尝试到 8010。

在原项目中也可以双击 `demo/start-demo.cmd`，或运行：

```powershell
.\.venv\Scripts\python.exe demo\launch.py
```

## 演示内容

- **挑战强化 AI**：选择执黑或执白，点击棋盘落子，可虚手、认输、回看和导出 SGF。
- **AI 对战**：强化版与原始版使用同一个推理程序、不同权重，可以连续观看或逐手走棋。
- **真实评测回放**：全部 200 局独立测试均可回放，包含胜局和负局，可筛选、调速、拖动手数和导出。
- **训练成果**：四轮训练数据、主评测结果与辅助检查，附可下载的评测报告。
- 原有完整对局工具保留在 `/arena`。

## 数据口径

主评测为强化模型对原模型 139 胜、61 负，胜率 69.5%。共 100 个固定新开局，各交换一次黑白，双方每手 64 次搜索。该成绩不是线上积分或通用棋力等级。

实时演示使用冻结的评测版权重、C++ 推理程序和每手 32 次搜索。中国数子、贴 7.5 目、禁自杀、全局同形、连续两次虚手终局，死子需实际提掉。重启后会恢复真实历史，规则引擎负责校验所有落子。

Demo 的模型位于 `demo/models/`，与项目中后续修改的 `submission/` 分开。模型文件在运行前核对校验和，不会静默替换为随机 AI。启动器使用单独的 `data/demo.db` 保存演示对局。

## 用于展示的三分钟流程

1. 在「挑战 AI」落几手，展示真实模型应答。
2. 切换「AI 对战」启动强化版对原版，点暂停和单步。
3. 切换「评测回放」选择任意一局，调到 4×，拖到终局看数子结果。
4. 打开「训练成果」，解释 256 局训练、21,300 个新增局面和 200 局独立评测。

服务只监听本机地址。共享给其他 Windows 用户时，发送整个 ZIP 并解压后运行。
